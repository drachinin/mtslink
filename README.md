# МТС Линк — автоподтверждение

Расширение для **Google Chrome** и **Microsoft Edge**, которое автоматически нажимает **«Подтверждаю»** в окне контроля присутствия МТС Линк.

## Установка

Скачайте репозиторий через **Code → Download ZIP** и распакуйте архив.

В папке расширения должны находиться:

```text
manifest.json
content.js
```

### Google Chrome

1. Откройте `chrome://extensions/`
2. Включите **Режим разработчика** (тумблер сверху справа)
3. Нажмите **Загрузить распакованное расширение** (кнопочка сверху слева)
4. Выберите папку, содержащую `manifest.json`
5. Обновите страницу конференции

### Microsoft Edge

1. Откройте `edge://extensions/`
2. Включите **Режим разработчика** (тумблер снизу слева)
3. Нажмите **Загрузить распакованное расширение** (кнопочка сверху посередине)
4. Выберите папку, содержащую `manifest.json`
5. Обновите страницу конференции

## Использование

Расширение запускается автоматически на доменах `mts-link.ru`, `webinar.ru` и их поддоменах.

Оставляйте вкладку конференции открытой. При первом появлении окна проверьте, что подтверждение сработало.

Отключить расширение можно на странице управления расширениями.

## Устранение ошибок

### Кнопка не нажимается

- Убедитесь, что расширение включено, и обновите страницу конференции.
- Если конференция открыта на другом домене, добавьте его шаблон в `matches` файла `manifest.json`.
- Откройте **F12 → Console**. При попытке нажатия появляется сообщение:

  ```text
  [МТС Линк] Нажата кнопка «Подтверждаю»: …
  ```

  Это означает попытку клика, но не гарантирует, что сайт принял подтверждение.

- Если разметка сайта изменилась или сайт блокирует программные клики, потребуется доработка `content.js`.

### Не работает в фоновой вкладке

Добавьте сайт конференции в исключения:

- **Chrome:** `chrome://settings/performance` → **Всегда оставлять эти сайты активными**.
- **Edge:** найдите в настройках **Спящие вкладки** и добавьте сайт в исключения.

Это снижает риск приостановки вкладки, но не исключает фоновые задержки.

**Во время сна компьютера расширение не работает.**
